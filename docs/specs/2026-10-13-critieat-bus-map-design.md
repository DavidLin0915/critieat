# CRITIEAT 公車地圖原型 設計

日期：2026-10-13　狀態：原型已實作（`proto/v1/bus.html`），待審核

## 目的

中午常搭公車去買午餐，但南港一帶公車與路線很多，要一直查「哪台公車有到哪站」。
公車地圖把昆陽站～南港車站～南港軟體園區一帶的站牌與路線放在 Google 地圖上，回答兩個問題：

1. 這個站牌有哪些公車、從這裡不用轉車可以到哪些站？
2. 某台公車（306、藍15、藍23…）停哪些站、怎麼走？

## 決定事項（2026-10-13 與使用者確認）

| 項目 | 決定 |
|---|---|
| 即時到站時間 | 不做，只要路線與站牌 |
| 點站牌之後 | 列出停靠的公車，並在地圖上亮起可直達的站；再點亮起的站看要搭哪台 |
| 路線顯示範圍 | 整條路線都收，地圖預設停在南港 |
| 與美食地圖連動 | 只在地圖上標出店家位置（可開關），不做自動配對 |
| 資料來源 | TDX，以免金鑰方式抓一次存成靜態檔，頁面不直接呼叫 TDX |

## 範圍

- **入口站牌**：離「昆陽站 — 南港車站 — 南港軟體園區」折線 650 公尺以內的站位（目前 92 個）。地圖常駐顯示，也是唯一能當「上車站」的站。
- **收錄路線**：只要有停靠任一入口站牌的路線都收（台北市＋新北市，目前 81 條），每條都是完整的停靠站與路徑。
- 範圍外的站位只在「可直達」或「路線檢視」時出現。

## 資料

- 產生方式：`node docs/bus/fetch-bus-data.js` → `proto/v1/js/bus-data.js`（約 240 KB）。說明見 `docs/bus/README.md`。
- TDX 端點：`Bus/StopOfRoute/City/{Taipei,NewTaipei}`（依範圍過濾）、`Bus/Shape/City/{…}`（依路線過濾），共 4 次呼叫。
- **站位**以 TDX 的 `StationID` 為單位：同名站牌在馬路兩側是不同站位、方向相反，各自只列那一側的公車。
- **走法**（pattern）：同一路線、同方向、停靠站完全相同的子路線（狗狗公車、不同業者、去程半…）併成一筆；停靠站不同的（如 306 三重／大都會）各自保留。
- 資料格式：`stations { 站位ID: [站名, 緯度, 經度] }`、`entry 站位ID[]`、`routes[].patterns[] { name, dir, stops, shape }`、`shapes`（Google encoded polyline）。

## 畫面與操作

沿用美食地圖的風格、頁首與三欄版面；兩頁導覽列的「公車地圖」皆可點。

- **左欄**：搜尋框（站名或路線）＋「站牌／路線」兩個分頁。同名站牌用「往 ○○」（最多路線的下一站）區分方向。
- **地圖**：入口站牌為白色圓點；右上「顯示店家」開關，店家為紫色小方塊。
- **選了站牌**：該站變黑色大圓點，可直達的站變青色，到不了的入口站牌變淡。右欄列出停這站的公車（「終點在這站」的另列）與同名站牌。
  - 點青色的站 → 右欄顯示「A → B」可搭的公車與各坐幾站。
  - 點其他入口站牌 → 換成新的上車站。
- **選了路線**：地圖畫出路徑（含方向箭頭）與停靠站；右欄可切換走法（往哪裡），依序列出停靠站，範圍外的站為淡色。
  - 從站牌點進來時，清單上標出「上車／下車」與中間區段，並自動捲到上車站。
  - 「看整條路線」把地圖縮放到整條路徑。

## 出錯處理

- 地圖載不出來（沒 Key、Key 不允許該網址、網路錯）：顯示「地圖暫時無法使用」，清單與詳情照常可用。
- 走法沒有路徑資料（目前 2 種）：以停靠站直線相連代替。
- 資料檔沒載入：清單顯示錯誤訊息。頁首標示資料來源與抓取日期。

## 檔案

| 檔案 | 用途 |
|---|---|
| `proto/v1/bus.html` | 頁面 |
| `proto/v1/js/bus-data.js` | 靜態資料（腳本產生，勿手改） |
| `proto/v1/js/bus.js` | 純邏輯：索引、停靠公車、可直達、兩站之間、路徑解碼 |
| `proto/v1/js/bus-map.js` | Google 地圖：站牌圓點、路徑、店家 |
| `proto/v1/js/bus-app.js` | 狀態與左右欄畫面 |
| `proto/v1/css/style.css` | 末段新增「公車地圖」樣式 |
| `docs/bus/fetch-bus-data.js` | 向 TDX 抓資料的腳本 |

## 這一版不做

即時到站、轉乘規劃、班距與時刻表、票價、捷運、店家與站牌自動配對、以範圍外的站當上車站。
